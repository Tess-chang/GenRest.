# 🍽️ GenRest - AI 餐廳推薦系統
網站:https://genrest.onrender.com

**GenRest** 是一個基於 Flask 架構的 AI 餐廳推薦網站，整合 Google Places API 與台大建築座標資料，能根據使用者所在位置、用餐預算、餐飲偏好與時間需求，智慧推薦適合的餐廳。

---

## 🚀 功能特色

### 🧭 一日推薦
- 選擇你所在的 NTU 建築物
- 設定可接受的距離、預算與餐廳類型
- 顯示最多 3 家推薦餐廳（優先顯示營業中）

### 📅 多日行程規劃
- 自訂推薦起訖日期
- 為每一天設定早餐／午餐／晚餐的推薦條件
- 一鍵產生餐廳行程表

### 🗺️ 地圖整合
- 所有推薦結果皆附上地圖連結
- 可於 Google Maps 中快速查看店家位置

### 💡 備援策略
- 當找不到符合條件的餐廳時，會退而推薦鄰近營業中店家作為備案

### 💰 智能記帳系統（整合擴充）
- 記錄每日支出（自動帶入推薦店名與日期）
- 分類分析與支出統計
- 支援設定每月預算與過度消費提醒
